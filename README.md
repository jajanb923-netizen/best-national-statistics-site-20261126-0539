NusaStat — Statistik Indonesia: penduduk, ekonomi, kesehatan, dan 38 provinsi dalam angka, 2015–2024. Data World Bank (WDI) dan Badan Pusat Statistik, lengkap dengan sumber dan tahun. Situs statis tanpa framework: HTML + CSS + modul ES, grafik SVG digambar dari data.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Build the entry with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
